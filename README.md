# 游戏工作室

手机竖屏独立游戏工作室经营原型。双击 `start.cmd` 本地试玩，需要 Python 3。浏览器将打开 http://127.0.0.1:8766/。

从第 1 年第 47 周开始。给工作室取名，招齐 2 名开发和各 1 名产品、美工、测试、市场后，游戏日历开始自动推进。立项会自动分配工时，研发随游戏日历每周结算一次，右上角可选 1×、2× 或 4×。项目依次经历开发、测试和改 BUG，至少制作 4 周才能发售。年底自动公布六大奖项，未发行项目可以跨年继续。已发售作品在项目页逐周结算销量，售满 12 周自动下架。

在「团队 → 在职成员」可以加薪或解雇。高级企划随公司等级解锁，需支付立项费并预留研发开支。工作室随机事件出现时会暂缓日历，选定处理方式后继续。

员工月薪按在职周数累计，每四个游戏周结算一次。团队页会显示下次发薪日期，财务账本可查看本月待付工资和扣除这笔工资后的可用现金。

右上角可手动暂停和继续。切到后台或约五个游戏周未操作时，经营会自动暂停。离席期间如果下一次发薪预计会耗尽现金，也会在结算前暂停。

在「研发」点「制作游戏」，先选游戏类型，再定剧情和美术风格。作品名称可手动输入，也可按类型随机生成。确认名字后开始开发，发售后可在「项目」回看这些设定。

招齐团队后，可在「研发 → 外包委托」接测试、美术或原型订单。订单占用对应岗位的工时，交付后一次回款。「团队 → 在职成员」可安排两周培训。测试员工完成自动化测试培训后，公司达到 Lv.2 即可制作连锁机关沙盒。

不同类型偏好不同的剧情和美术搭配，发售后可发现组合效果。首批销量结算后会出现四类玩家评论，好作品在售卖期积累对应群体的粉丝。员工可能提出需要额外工期的创意；参与完成作品会积累类型经验，高评分作品还会提升员工技术。

游戏入口位于 `src/app.js`，经营规则位于 `src/core/`。开局与清算、团队、立项、研发、作品档案、年度榜单和采购的界面分别位于 `src/modules/screens/`，设置与存档界面位于 `src/modules/settings-screen.js`。原型使用浏览器本地存档，TapTap H5 客户端接入和真机验证待完成。

`src/core/studio.js` 是经营规则的统一入口，负责推进游戏周。立项、开发和项目评分在 `production.js`，定价与发售在 `release.js`，销售回款、促销和更新在 `sales.js`，年度榜单、竞品和奖项在 `annual.js`，工资和收支账本在 `ledger.js`。

`src/modules/` 下的 `game-clock.js` 管理时间倍速和每周触发，`project-controls.js` 管理立项和续作表单，`save-controls.js` 管理选档与手动存档操作。
